# 🧮 Numerical Simulations for Fr´ echet Sufficient Dimension Reduction for Metric Space-Valued Data via Distance Covariance


The simulations are implemented in Python and reproduce the results from the paper. All core methods and algorithmic implementations are organized in the `functions/` directory.

This repository includes original contributions from our work, as well as implementations of methods from prior literature:
1. FOPG based on:
   Qi Zhang, Lingzhou Xue, and Bing Li. Dimension reduction for Fr´ echet regression. Journal of the American Statistical Association, pages 1–15, 2023.

2. GWIRE based on:
   Jiaying Weng, Kai Tan, Cheng Wang, and Zhou Yu. Sparse Fr´ echet sufficient dimension reduction with graphical structure among predictors. arXiv preprint arXiv:2310.19114, 2023.
